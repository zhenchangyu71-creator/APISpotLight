# 导出确认接口

**APISpotLight · 阶段 2 · MCP: `export_confirmed_apis`**

## 前置检查

1. 确认 Cursor MCP 中 **`api-spotlight`** 可用。
2. 用户已编辑阶段 1 的 `candidates.json`（`selected=true/false`）；未匹配项若要导出，须把 `path` 改成文档中的规范模板路径并设 `selected=true`。

## 收集参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `api_doc_source` | 是 | **优先**阶段 1 返回的 `openapi_cache_path`（`full-openapi.from-torna.json`）；否则本地完整 OpenAPI，或同一 Torna 项目链接 |
| `candidates_path` | 是* | 已编辑的 `candidates.json`（与 `confirmed_apis` 二选一） |
| `output_path` | 是 | 精简文档输出路径；不得覆盖源 OpenAPI |
| `output_format` | 否 | `json` / `yaml` / `markdown` / `openapi`（默认） |

\*也可直接提供 `confirmed_apis` 数组，此时不要再传 `candidates_path`。

## 执行步骤

1. 若用户刚跑过 `/查找页面接口` 且有 `openapi_cache_path`，默认建议用该缓存，勿无故再传 Torna URL。
2. 调用 MCP **`export_confirmed_apis`**，传入收集到的参数。
3. 汇报：导出路径、导出接口数、格式，以及返回中的警告（若有）。

## 注意

- 不要只改 `candidates.md`；阶段 2 读的是 `candidates.json`。
- Token 仅通过环境变量 `TORNA_TOKEN` 注入；工具参数中禁止携带 token。
